# 睦灵科技介绍

（供庄磊总转呈王凭慧教授，探讨场景合作机会）

## 一、公司概况

睦灵科技（杭州）有限公司成立于 2026 年，是一家专注**具身智能"大脑"模型**的科技公司。公司不做机器人本体、不自产灵巧手，专注打造**跨本体的通用操作大脑**，与本体及灵巧手厂商生态合作，将具身智能落地到真实物理场景。

- **团队**：核心团队二三十人，均为模型/算法背景，自国内头部互联网企业具身智能团队成建制组建
- **融资**：首轮融资即将关闭，投后估值约 20 亿元人民币
- **路径**：以"模型能力 + 场景生态"双轮驱动，与产业方共同验证、共同落地

## 二、核心技术

**1. 三层同源的"大脑"架构（System 2 / 1 / 0）**

- System 0：闭环物理稳定控制（类比"小脑"）
- System 1：端侧灵巧操作（视觉 + 无本体数据学习）
- System 2：自主推理与长程任务进化

三层模型同源训练，使机器人具备"端侧灵巧操作 + 自主推理"的全栈能力——不仅能执行动作，还能理解任务、处理异常、持续进化。

**2. 触觉世界模型**

以触觉为核心的物理世界理解能力：在无视觉条件下仅凭触觉完成旋转物体等精细操作，通过"视觉 + 触觉 + 时间"多因子融合判断物理状态。触觉优先路线天然适配**柔性物料、线缆、异形件**等视觉方案难以处理的操作对象。

**3. 数据管线**

百万小时级无本体数据（人类操作数据 + 穿戴式采集 + 仿真合成）与真机数据结合，通过异构本体（不同手、不同臂）混合训练，实现跨本体的快速泛化。

## 三、落地进展

公司当前聚焦**半结构化、高频、高价值**的产业场景，已在以下方向与头部机构建立合作：

- **医学检验/生命科学**：与云康集团达成战略合作（MOU），围绕样本处理、制片捞片等实验室场景开展概念验证（POC）
- **工业检测**：与检测行业自动化伙伴对接拆包、贴标、接线/插拔测试等环节的灵巧操作自动化
- **物流与商业场景**：物流分拣（拆袋、取件、扫码、上料）等场景已具备可演示能力

## 四、与商业航天的结合点

商业航天正从"单件定制"进入**批产组网时代**：千帆星座一期 648 颗、2030 年目标超 1.5 万颗，民营卫星厂（格思航天、银河航天、微纳星空等）相继建成年产百颗级生产线。我们注意到，行业产能爬坡的真正瓶颈不在搬运层（AGV、助力臂已普及），而在**操作层**——卫星总装中大量工序至今高度依赖资深装配工程师的手上经验，熟练工短缺已成为扩产的第一约束。其中存在大量当前自动化设备难以覆盖、恰与睦灵技术能力高度匹配的灵巧操作环节：

1. **卫星批产总装**：线缆接线与插拔、线束整理、接插件装配——柔性线缆与部分盲插操作是传统专机的空白区，恰是触觉优先灵巧操作的优势区间
2. **柔性物料处理**：多层隔热组件（MLI）、薄膜等柔性物料的抓取、包覆与装配——行业内公认的人工难点
3. **装备测试验证**：传感器布设与粘贴、测试台上下料、载荷测试操作等工位
4. **面向未来的复用火箭检修**：可回收火箭进入密集首飞阶段，复用翻新将形成高频、重复的检修操作需求

此外，在**低空经济**领域，工业级无人机总装的接线/插拔、载荷安装等环节也存在同类的灵巧操作机会，可作为延伸场景。

王凭慧教授在型号研制、商业航天产业与智能制造领域的深厚积累，正是我们最需要的产业指引。我们诚挚希望借助王教授及**深圳市先进航空航天技术研究院**、**粤港澳智能制造产业联盟**的资源与指导，与产业内的卫星/火箭制造及总装测试单位建立场景对接，以"客户出场景视频 → 联合评估 → 单工位 POC 验证"的轻量方式启动合作。
