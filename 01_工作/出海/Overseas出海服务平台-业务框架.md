# Overseas 出海服务平台 · 业务框架

> 版本：v1.0　|　用途：下周沟通会材料　|　说明：T = Teddy（海外线），A = Anson（国内线）

---

## 一、定位与背景

**一句话定位**：Overseas 是国内出海企业与海外资源（银行、金融机构、企业客户、政府机构）之间的"中间赋能"平台——T 管香港及海外，A 管国内触达。

**底层逻辑**（电话沟通已达成共识）：
- 港深两地各设一家合资公司，初期各持 50%；
- 聚焦**科技型企业出海**的专业服务；
- 客户分三阶段经营，服务由轻到重，收费由免费到股权。

---

## 二、聚焦赛道与选择逻辑

| 赛道 | 出海形态 | 核心痛点 | 对 Overseas 的价值 |
|---|---|---|---|
| **工业自动化与机器人** | 产品 + 集成出海 | 本地场景验证、集成商渠道、认证合规；缺海外售后网络 | 中国成本优势最硬，东南亚制造业升级刚需，标准化程度高、可复制 |
| **Digital AI 应用** | 产品 / 解决方案出海 | 本地化部署（语言、数据合规）、标杆客户获取、算力与云 | 东南亚缺 AI 生态、欧美方案贵，是 T 判断的直接落点 |
| **具身智能** | 技术合作 + 早期出海 | 联合研发、场景数据、样机试点、技术授权 | 早期但资本关注度高，是 FA + 股权置换的最佳标的池 |
| **创新药 License-out** | **IP 出海**（非实体出海） | BD 撮合、跨境 IP 架构与税务、里程碑付款设计、海外注册 | 单笔价值极高，香港 18A 是天然跳板，是香港资源最高效的变现场景 |
| **新能源 / 数字经济** | 项目 + 重资产出海 | 项目开发与 EPC 伙伴、项目融资、牌照与并网、IRA / CBAM 合规 | 单项目金额大，项目融资顾问费可观，能带动银行资源 |

> **关键判断**：这五类客户恰好是"愿意为专业服务付费、且能把服务费转化为股权"的群体，与行业报告中"企业最愿付费的五项——财税 64%、政策 57%、法律 48%、融资 42%、资源对接 39%"完全重合。

## 三、分阶段服务矩阵

### 3.1 通用底盘（三阶段）

| 阶段 | 客户状态 | 核心痛点 | Overseas 服务产品 | 收费模式 | 主责 |
|---|---|---|---|---|---|
| **① 启蒙期** | 有想法未行动 | 不知从哪走、政策不熟（57%） | 免费 Workshop、国别市场研究报告、出海自测诊断、政策解读会、合规红线清单 | 免费 / 低价（蓄客） | A 组织，T 出内容 |
| **② 进入期** | 决定出海 / 刚落地 | 架构、合规、渠道、人才（合规 3.53、人才 3.52） | ① 跨境架构设计（港/新控股 + ODI 协同）<br>② 目标市场落地（注册、牌照、税务、劳动法）<br>③ 渠道搭建（分销商 / 集成商招募撮合）<br>④ 场景 POC 试点（泰国银行模式复用）<br>⑤ 财税合规（外包给生态会计所 / 律所）<br>⑥ 人才与组织 | 固定顾问费 + 落地项目费 + 生态分包佣金 | T 交付海外，A 对接企业 |
| **③ 扩张期** | 已运营、要放大 | 融资、上市、供应链、并购（融资需求 42%） | ① 跨境融资 FA（VC / PE / CVC / 家办 / 美元基金）<br>② 上市辅导（港股 18A / 18C、A+H、ASX）<br>③ 产能与供应链出海（建厂 / 合资）<br>④ 品牌 PR 与政府关系 | FA 3–4% + 股权置换 5–10% | T 找资本，A 找项目 |

### 3.2 行业差异模块（在通用底盘上加挂）

| 赛道 | 阶段② 专属模块 | 阶段③ 专属模块 |
|---|---|---|
| 工业自动化与机器人 | CE / UL 等安规认证、系统集成商招募、售后网络搭建 | 合资建厂、海外订单融资 |
| Digital AI | 数据跨境合规方案、标杆客户 POC、云与算力对接 | 本地合资、SaaS 出海融资 |
| 具身智能 | 联合实验室 / 试点场景撮合、技术授权架构 | 早期轮 FA（最易转股权） |
| 创新药 License-out | BD 撮合与谈判顾问、跨境 IP 架构与税务、NewCo / 里程碑付款设计 | 港股 18A 上市辅导、后续并购退出 |
| 新能源 / 数字经济 | 项目开发与 EPC 伙伴撮合、本地牌照与并网 | 项目融资顾问（银行资源变现主力） |

### 3.3 变现路径（四层递进）

```
免费 Workshop 引流  →  固定收费顾问服务  →  FA 按融资额 3–4%  →  长期股权置换 5–10%
   （蓄客、建池）        （现金流、验证能力）    （单笔高毛利）        （长期资产、最大收益）
```

## 四、T 需整合的香港及目标市场资源

### 4.1 香港（"超级连接器"层）

| 类型 | 具体机构 | 用途 |
|---|---|---|
| 政府 / 公共背书 | 投资推广署（InvestHK）、贸促局（HKTDC）、数码港、科技园（HKSTP）、生产力促进局（HKPC） | MOU 背书、联合办会、客户导流 |
| 资本市场 | 港交所（18A / 18C 通道）、持牌券商 / 投行、PE / VC、家族办公室、资管机构 | FA 与上市辅导、美元基金 LP |
| 金融机构 | 跨境银行（贸易融资、项目融资、内保外贷）、跨境支付机构 | 落地金融方案、客户推荐 |
| 专业服务 | 律所（跨境并购 / IP / 数据合规）、会计师事务所（税务架构 / 转让定价）、信托及公司服务提供者 | 服务分包生态，补齐专业深度 |
| 科技生态 | 高校（港大 / 科大 / 中大）成果转化、InnoHK | 具身智能 / 创新药技术合作 |

### 4.2 泰国（首选战场）

- **官方**：BOI（投资促进委员会，拿税收优惠与落地便利）、商务部
- **金融**：**大型商业银行**（已有合作，可复制为"银行客户 AI 赋能"模板）、当地券商
- **产业**：制造业园区（Amata、WHA）、系统集成商、华人商会网络
- **需求侧**：当地企业数字化转型（AI 缺口大）→ 对接中国 AI / 机器人供应商

### 4.3 马来西亚

- MIDA（投资发展局）、当地上市公司与家族企业集团、华人商会、工业园（柔佛 / 槟城，半导体与电子聚集）

### 4.4 澳大利亚（最成熟市场）

- Austrade（贸易投资委员会）、各州贸易投资局、ASX、律所与会计师事务所、R&D Tax Incentive（研发税收返还，对科技企业吸引力强）

> **T 的核心 KPI**：每个市场确认 2–3 家"靠谱、能落地交付"的伙伴（partner 靠谱度第一），统一纳入 Overseas 的服务交付网络。

## 五、A 的境内获客管道

| 管道 | 具体对象 | 打法 |
|---|---|---|
| **政府 / 半官方** | 地方商务厅、贸促会（CCPIT）、工信与发改部门、地方"出海服务港"、园区（张江、苏州工业园、深圳、合肥） | 承接官方服务体系落地环节，做"市场化专业节点"；联合调研与发布会 |
| **行业协会 / 联盟** | 机器人产业联盟、具身智能联盟、医药创新促进会、光伏 / 储能协会、AI 产业联盟 | 协会背书 + 闭门会导流 |
| **金融机构** | 银行公司金融 / 跨境金融部、券商投行部、PE / VC 被投企业 | 客户经理转介绍（企业出海金融需求天然前置） |
| **产业链主** | 比亚迪 / 宁德 / 华为等链主企业上下游 | 跟随"链主出海"批量获客 |
| **高校科研** | 高校成果转化中心、校友网络 | 技术型企业源头 |
| **会展活动** | 世界机器人大会、进博会、SNEC、CMEF、BIO 大会 | 现场获客 + 品牌曝光 |
| **内容与转介** | 联合研究报告、行业媒体、律所 / 会计所转介 | 低成本持续线索 |

**管道优先级**：
- **短期**（0–3 个月）：政府 + 银行——见效快、批量大
- **中期**（3–6 个月）：协会 + 内容——沉淀品牌与行业影响力
- **长期**（6 个月以上）：链主 + 高校——构建高价值标的池

## 六、股东层面的核心伙伴选择

### 6.1 A 侧重（境内资源背书）

| 层级 | 候选类型 | 对 Overseas 的价值 | 绑定方式建议 |
|---|---|---|---|
| 政府 / 园区平台 | 地方投资促进机构、贸促会、园区运营平台 | 官方信任 + 客户线索 + 政策资源 | **MOU + 顾问委员会**（不建议直接持股，规避审批周期） |
| 金融机构 | 全国性银行跨境金融部、券商投行 | 客户转介 + 融资通道 + 资质背书 | 战略合作 + 小比例股权（可选） |
| 产业资本（CVC） | 链主企业投资部 | 项目源 + 产业资源 + 后续退出通道 | 5–10% 股权绑定 |
| 行业协会 | 机器人 / 医药 / AI 产业联盟 | 行业公信力 + 会员导流 | 战略合作，不入股 |

### 6.2 T 侧重（境外资源背书）

| 层级 | 候选类型 | 对 Overseas 的价值 | 绑定方式建议 |
|---|---|---|---|
| 香港公共机构 | 数码港、科学园、投资推广署 | 国际背书 + 品牌可信度 | **MOU 优先**（公共机构通常不入股） |
| 持牌金融机构 | 香港券商 / 资管、泰国大型银行 | 客户 + 资本 + FA 通道 | 战略股东（小比例）+ 合资业务 |
| 专业服务机构 | 香港律所 / 会计所 | 交付能力补齐 + 转介 | 合作联盟，不入股 |
| 本地产业伙伴 | 泰国 / 马来 / 澳洲本地财团或上市公司 | 落地执行 + 本地政商关系 | **关键资源方给 5–10% 股权** |

### 6.3 股东结构设计原则

1. **初期维持港深两地 50:50**，后续视贡献与关键资源方引入调整；
2. 预留 **10–20% 期权池**，专门给"关键资源方"（本地伙伴、持牌机构、产业资本）；
3. 区分**战略资源股东**（小额、强背书、带资源）与**财务股东**（真实出资），避免"股权稀释了却换不来资源"；
4. **风控**：政府 / 国资类伙伴直接入股涉及审批，易拖慢节奏——**一律优先用 MOU + 顾问委员会**处理。

## 七、资质与合规要点（业务架构中前置解决）

| 事项 | 要求 | 建议处理方式 |
|---|---|---|
| FA 业务 | 香港从事证券相关顾问需 SFC 1 / 4 / 6 号牌照 | 前期**与持牌机构合作分成**，或直接申请牌照 |
| 境内募资 / 基金管理 | 需私募基金管理人备案 | 由境外持牌主体承接 |
| 公司服务类业务（注册、秘书） | 需香港 TCSP 牌照 | 自建或与持牌秘书公司合作 |
| 数据合规（AI / 医药） | 跨境数据传输合规 | 靠生态律所支撑，不自建 |
| 出口管制 | 部分技术 / 设备受限 | 靠生态律所支撑，不自建 |

## 八、总结与下一步

**一句话总结**：
T 用"香港持牌 + 公共机构背书 + 本地产业伙伴"解决**资质与落地**；A 用"政府 / 园区 + 银行 + 产业资本"解决**客户与项目源**；股东层只让"能持续带资源的伙伴"进来，纯背书关系用 MOU 处理。

**下周沟通会待确认事项**：
1. 五大赛道的**优先级排序**（建议先切工业自动化与机器人 / AI 应用，再补创新药与新能源）；
2. 泰国银行合作案例的**商业化包装方案**由 T 主笔；
3. 首批**试点企业名单**与 T / A 各自的推进节奏；
4. 股东结构、期权池比例与关键资源方的绑定原则；
5. 下次碰头前需整合的**双方调研成果 + 业务框架 PPT** 分工与截止时间。
