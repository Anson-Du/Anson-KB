# 新公司出海服务平台 · 业务框架（0918 版）

> 本版按"定位 → 赛道 → 服务产品 → 交付与收费 → 团队 → 获客 → 案例验证"重构叙事；正文保持单线、简洁。

## 一、业务定位

**一句话定位**：**新公司**是中国出海企业与海外资源（银行、金融机构、企业客户、政府机构）之间的"中间赋能"平台——T 负责海外资源协调与服务交付，A 负责国内客户触达。

**三条底层共识**：

- 港深两地各设一家合资公司，初期各持 50%；
- 聚焦**科技型企业出海**的专业服务；
- 客户分三阶段经营（启蒙 → 进入 → 扩张），服务由轻到重，收费由免费到股权。

**Day1 不铺开团队原则**：

- **编制锁定 T + A（原"T + 1 助理 + A"方案中助理角色取消），半年内除 T 外最多加 1 人；**
- 属地第一笔订单签约前不招属地人员——属地是"需要 partner 承接的地方"，不是"需要拔人的地方"；
- 交付全部走生态：⑦ 授权集成服务商池、⑧ FDE 配套生态、③ 律所/会计所分包；资源整合优先于人员扩充；
- 三不边界：不卖设备、不做系统集成、不出资金不压货；所有收费与合同边界写清、主体清晰、金额合规、不碰现金、不碰记名（FCPA / UKBA 红线）。

## 二、聚焦行业赛道

**结论（两档制，不设 P2）**：

| 赛道 | Day1 优先级 | 一句话理由 |
|---|---|---|
| **Digital AI 应用** | **P0 · 标杆主攻** | 交付门槛最低（短周期现场），是 T 判断的直接落点；一个银行级项目即可撑起首年收入 |
| **工业自动化与智能装备** | **P0 · 现金流主攻** | 服务产品最成熟（②③④⑤），⑦ 集成商池 Day1 可搭；东南亚制造业升级刚需、中国优势最硬 |
| 具身智能 | P1 · 只建池 | FA + 股权置换的最佳标的池，早期不出单 |
| 创新药 License-out | P1 · 只建池 | 单笔价值极高、香港 18A 天然跳板，但 BD 周期长，不计入现金流 |
| 新能源 / 数字经济 | P1 · 只建池 | 重资产依赖项目融资与银行资源，待生态沉淀后启动 |

**P0 判据三条**：

1. Day1 可交付——不依赖自建资产；
2. Day1 可变现——客户有预算、已进入决策；
3. T 的港/东南亚关系是直接落点。不满足者进 P1——只建池、不做主攻投入。

**双主攻分工**：资源冲突时优先保"当周能签单/收款"的一方（工业自动化与智能装备的 ②③④⑤），Digital AI 按里程碑推进。**P0 半年验收**：工业自动化与智能装备——②③ 有 ≥3 个可公开案例、⑤ 第一笔放款到账；Digital AI——≥1 个标杆客户 POC 转生产（泰国银行模式复用）。

> **关键判断**：五类客户都是"愿意付费、且能把服务费转化为股权"的群体，与调研报告中"最愿付费五项——财税 64%、政策 57%、法律 48%、融资 42%、资源对接 39%"高度重合。

## 四、业务交付与收费模式

### 4.1　交付规则

- **主体与币种**：境外业务以香港主体收 USD/HKD（便于付境外生态），境内客户以境内主体签人民币合同；两套主体差异化报价，境外可高 10–15%。
- **报价顺序**：永远先报 L1 诊断（免费 / 1–2 万），拿到信息后再报 L3 完整包；不一上来报大包，否则转化率丢一半。
- **四层变现**：免费 Workshop（蓄客）→ 固定顾问费（现金流）→ FA 按融资额 3–4%（高毛利）→ 股权置换 5–10%（长期资产）。

### 4.2　收费体系

| 业务 | 性质 | 收费模式 |
|---|---|---|
| ② 标准化咨询包 | 固定价标准包 | L1 免费 / 1–2 万；L2 单模块 3–8 万；L3 完整包 15–30 万；转年度顾问 10–20 万/年 |
| ③ 生态分包交付（律所/会计所/认证/银行） | 总包 + 加价 | 对客户总包 ×1.3–1.5；认证 PM ×1.15–1.25；融资顾问 0.5–1.5% |
| ④ 售后网络搭建包 | 标准化产品 | 搭建费 10–20 万/家 + 工单抽成 10–20%（合同期锁定使用） |
| ⑤ 订单融资撮合 | 咨询 + 成功佣金 | 方案设计 5–15 万 + 融资额 0.5–1.5%；后续年顾问 5–10 万/年 |
| ① 跨境撮合（订单 + 集成商） | 介绍人 + 成功佣金 | 定位费 5–10 万 + 里程碑 10–20 万 + 首年佣金 8–12%（按回款） |

### 4.3　半年动作节奏（二十四周）

| 阶段 | 重点产出 | 结果验证 |
|---|---|---|
| W1–W2 | 跑通 ②④⑤ 产品化包 | 价格论证、合同模板、工具准备 |
| W3–W8 | ②③ 收入集中产出；推 ④ 名录与案例包 | W8 前交付 ≥1 个咨询包与 ≥1 个售后网络包；⑤ 跑通第一单 |
| W9–W24 | ⑤ 放量；④ 形成 1–2 个可引用个案 | ②③ ≥3 个可公开案例；⑤ 第一笔放款到账 |
| ① 跨境撮合 | 半年出 1 单即成功 | 不作为现金流依赖 |

### 4.4　一句话总结

> 半年内靠 ②③④⑤ 跑现金流，① 出单是锦上添花。

- **泰国（首选战场）**：BOI、大型商业银行（银行客户 AI 赋能模板）、Amata / WHA 制造业园区、华人商会网络。

## 七、有鹿机器人案例分析

> 有鹿大陆模式：代理商买断 → 长租给园区物业（绿城服务、万物云等）。在香港和澳洲复制时卡点在"钱谁出、谁决策、谁兜资产"，这恰是新公司的机会。

### 7.1　大陆模式的三个隐含前提

- **物业方信用强**：大陆园区物业多是开发商系/国资系，集中度高、单体大，能签长约、付得起租金；
- **属地代理商垫资**：代理商有资金实力买断设备再长租出去，靠属地关系铺渠道；
- **采购关系型**：大 B 客户少而集中，靠商务关系成交，不靠公开招标。

### 7.2　香港市场的差异点

**大陆**决策集中、**代理商垫资**，**香港**决策分散、双轨：商业物业由开发商系 PMC（置邦、港铁、太古等）决策；住宅屋苑由 **业主立案法团（IOC）+ 招标业主委员会** 决策，程序繁琐、对价格极敏感 → 没有"一单一大片"的大客户，逐个屋苑攻关成本高；采购流程更规范透明，反而利好"可量化绩效"的机器人。

**监管层：** PMSA 强制发牌（《物业管理服务条例》第 626 章，2020 年 8 月起持牌经营），物业公司 + 管业人员分级牌照 → 机器人作为"可量化绩效"产品反而是加分项。

**产业链层：** 清洁高度外判，PMC 把清洁再外判给清洁承办商，"价低者得"招标，承办商利润极薄（外判清洁工工资长期贴法定最低工资）→ **真正的使用者（外判商）没钱买设备** ——大陆模式里的"垫资方"缺位。

**人力层：** 老龄化 + 严重人手短缺，靠输入劳工计划补缺 → 机器人替代需求 **真实且刚性**，ROI 故事好讲；融资租赁发达但外判商主体小、信用薄，租不到 → 设备资产方和运营方分离，缺撮合与结构设计。

### 7.3　澳洲市场的差异点

**市场规模：** FM 市场约 AUD 600 亿+（2025），外包成熟度高 → 市场足够大，但门槛也最高；

**采购方式：** Tender/RFP 公开招标制，商业地产、政府、零售均走招标，投标需要本地主体、Public Liability 保险（常要求 $20M 级）、WHS（工作健康安全）合规文件、SLA 承诺 → **没有本地合规壳和服务能力，连标书都递不进去**；

**产业分工：** FM 整合商（ISS、Ventia、Downer、Sodexo 等）+ 专业清洁承包商多层分包 → "代理商"角色由 FM 承包商天然承担——但他们要的是 **能进 tender 方案的服务包**，不是买断设备；

**人力成本：** 清洁工时薪 AUD 30+，叠加养老金（super）和 Fair Work 法定成本，且全行业技能劳动力短缺 → **机器人 ROI 全球最强**，一台机器换人的账最好算；

**设备采购文化：** Equipment finance / chattel leasing 极成熟，按租赁/订阅采购是主流 → 租赁模式天然契合，但租赁公司要求资产认证与残值评估；

**产品合规：** RCM 电气认证、EMC、WHS 风险评估、Privacy Act（机器人摄像头涉及数据隐私） → 中国硬件进入的硬门槛，逐项可办但没人带路就慢。

### 7.4　新公司的机会

**香港机会 = 补位大陆模式中缺掉的"垫资方"**：

- **撮合**（L1）把有鹿对接的不是"代理商"，而是 **清洁承办商 + PMC** 两层——承办商缺设备、PMC 缺降本故事，新公司撮合"PMC 给长约承诺 → 承办商敢上机器人"的三角结构；
- **订单融资撮合**（L5）设计 **RaaS（Robot-as-a-Service）按清扫面积/时长计费** 结构，接入香港融资租赁公司作为资产持有方，解决"承办商没钱买"的死结——这正是框架里"订单融资撮合"的典型场景；
- **合规通道**：PMSA 持牌对接、招标文件、以及帮有鹿客户申请 **BUD 基金 / 科技券（TVS）** 等港府补贴，直接降低买方决策成本。

**澳洲机会 = 把"进标"变成服务**：门槛最高，因此服务费最硬。

- **合规与准入包**：RCM 认证、WHS 风险评估、保险对接、隐私合规——纯专业服务收入，与设备买卖无关，符合"不碰设备、不压货"边界；
- **渠道撮合**：对接 FM 整合商（ISS/Ventia 级别）做 pilot——他们不买设备，但愿意在 tender 方案里采用能降本的技术，新公司做的是 **技术供应商 ↔ FM 承包商** 的撮合；
- **租赁结构设计**：澳洲 equipment finance 市场成熟，撮合"租赁公司持有资产 + 承包商按月付费"的结构，并帮租赁方做 **中国机器人资产的残值评估与供应商尽调**——双方都缺的能力。

> 一句话定位：香港 = 补位垫资方（RaaS + 融资租赁撮合）；澳洲 = 把"进标"变成服务（合规准入 + FM 渠道撮合）。两地共性印证了业务框架的核心判断——中国 AI/机器人公司出海，卡的不是产品，是订单结构、资金安排和合规准入，这正好是新公司的整个生意。
