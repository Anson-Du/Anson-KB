# RoboX第一梯队场景合作方推荐
编制日期： 2026年8月6日 编制人： Anson 适用场景： 高端餐饮明档、酒店客房服务、康复辅助与按摩

## 一、场景筛选逻辑
RoboX手眼脑系统的核心能力锚点是灵巧操作——工具切换、力度感知、精细操控、长程任务规划。第一梯队的三个场景共享以下特征：接触操作丰富且需要灵巧手（而非夹爪）、容错性中等偏高、客单价支撑设备投入、任务可抽象为有限技能包、具备标杆展示价值。
以下按”技术匹配度 × 商业可行性 × 对接难度”综合排序，推荐近期应率先接触的合作方。

## 二、高端餐饮明档（铁板烧/中式炒菜/烘焙）
### 首选合作方
1. 长虹集团 - 对接状态：已有初步接触（田明提及与长虹集团董事长沟通合作） - 匹配理由：长虹旗下有酒店和文旅资源，自带高端餐饮场景；拥有工程化团队，可承接RoboX”基础产品+二开”的落地模式；同时是家电品牌方，未来进家庭场景有协同空间 - 切入点：将铁板烧/明档料理作为长虹酒店餐饮的”科技体验”项目，联合打造第一个餐饮标杆case - 建议对接人：长虹集团战略投资部或酒店业务板块负责人
2. 西湖文旅集团 / 洛阳文旅 / 四川文旅 - 对接状态：田明提到已主动联系RoboX，需求明确 - 匹配理由：文旅场景天然需要”体验感”和”话题性”，机器人做菜/服务自带传播力；移动餐车+户外餐饮场景可直接落地；有政府背景，利于政策资源联动 - 切入点：移动太空舱（榨果汁、烘焙、潮玩售卖）+ 固定餐饮明档组合方案 - 优先级：西湖文旅（杭州本地，地理最近）> 洛阳文旅 > 四川文旅
3. 王品集团 - 对接状态：待接触 - 匹配理由：旗下西堤牛排、石二锅等品牌均为明档/铁板类餐饮，标准化程度高，客单价300-500元，全国300+门店，是最匹配”煎牛排”demo能力的连锁餐饮集团 - 切入点：选1-2家旗舰店做”机器人主厨”试点，以科技感提升品牌溢价 - 建议路径：通过光源资本或产业投资人引荐餐饮行业资源
4. 开元酒店集团（德胧集团） - 对接状态：待接触 - 匹配理由：杭州本土高端酒店集团，旗下开元名都、方外等品牌有高端中餐和明档需求；总部在杭州，对接成本低 - 切入点：与长虹合作联动，在开元酒店内开设”机器人料理”体验区
### 补充推荐
海底捞：虽然火锅不是典型铁板烧场景，但其”超级智慧餐厅”已有机器人尝试，且对科技体验的投入意愿强。可作为远期品牌合作方。
香格里拉/君悦/瑞吉：APEC指定酒店（深圳罗湖会议中提及），高端西餐/铁板烧场景明确，可作为”政府+酒店+RoboX”三方合作的示范项目。

## 三、酒店客房服务（整理、补给、清洁）
### 首选合作方
1. 长虹集团（酒店板块） - 匹配理由：同上，长虹有酒店资源，客房服务是核心运营环节；客房整理、用品补给、台面清洁均为灵巧操作的典型场景 - 切入点：选一家长虹旗下酒店做”智能客房”试点，覆盖夜间和高峰时段
2. 华住集团 - 对接状态：待接触 - 匹配理由：中国最大酒店集团之一（全季、桔子水晶、漫心等品牌），对科技化运营的投入意愿强，已有机器人送物等初步尝试；门店基数大，一旦验证成功可快速复制 - 切入点：从桔子水晶或漫心等中高端品牌入手，以”机器人客房管家”为卖点 - 建议路径：华住总部在上海，可通过投资人网络或行业会议建立联系
3. 亚朵酒店 - 对接状态：待接触 - 匹配理由：亚朵以”人文体验”为品牌标签，对创新服务的接受度高；体量适中（1000+门店），决策链较短；总部在上海，但创始团队有互联网背景 - 切入点：亚朵S系列（高端线）或Z Hotel（生活方式线），做”智能服务体验房”
4. 杭州本地精品酒店/民宿集群 - 匹配理由：杭州是RoboX大本营，西湖/灵隐/西溪周边有大量高端精品酒店和民宿，决策链短，适合快速做小范围试点 - 切入点：选择1-2家标杆民宿做”机器人管家”体验项目，低成本快速验证
### 补充推荐
锦江集团（维也纳、丽笙等品牌）：国内门店数第一的酒店集团，但决策链较长，建议作为第二阶段目标。
万科·泊寓 / 龙湖·冠寓：长租公寓运营商，客房服务频次高且标准化程度高，可作为”服务机器人常驻”的场景验证。

## 四、康复辅助与按摩
### 首选合作方
1. 香港大学（已有合作基础） - 对接状态：会议中多次提及，已有合作推进 - 匹配理由：港大康复医学实验室有三年合作规划（明修提及），在康复手法标准化方面有学术积累；学术背书对后续医疗资质申请至关重要 - 切入点：加速推进已规划的Ego数据+触觉采集合作，先从非接触性康复动作（肩颈按摩、足底按压）开始验证
2. 浙江医院 / 浙江省康复医院 - 对接状态：待接触 - 匹配理由：杭州本地三甲医院，有康复科和脑卒中康复中心；省级医院对创新技术的接受度高于基层医院；与RoboX同处杭州，便于频繁沟通调试 - 切入点：以”辅助康复师训练”为切入（而非替代康复师），先在非敏感科室试点 - 建议路径：通过浙江省科技厅或卫健委的关系引荐（会议中提到省厅层面已有接触）
3. 翔宇医疗（688626.SH） - 对接状态：待接触 - 匹配理由：A股上市的康复设备龙头企业，产品线覆盖康复评定、训练、理疗全系列；有硬件渠道和医院客户资源，与RoboX形成”设备+智能”互补 - 切入点：为翔宇的康复设备加装RoboX的智能操作模块，做”智能康复工作站” - 建议路径：通过券商或产业投资人引荐
4. 大艾机器人 / 傅利叶智能 - 对接状态：待接触 - 匹配理由：专注康复机器人的创业公司，产品已进入多家医院；但它们偏重外骨骼和下肢康复，在手部精细康复（如手指训练、上肢协调）方面有空白，与RoboX的灵巧操作互补 - 切入点：技术合作或联合方案，而非直接竞争
### 补充推荐
泰康之家（养老社区）：泰康保险旗下高端养老社区，全国布局，对康复和照护机器人有明确需求，且付费能力强
优必选（09880.HK）：虽然是人形机器人公司，但在康养场景有布局，可作为”本体+大脑”的合作模式探讨对象

## 五、优先级矩阵与行动建议
### 近期行动建议
8月内（天使轮close前后）：
与长虹集团敲定合作框架，明确第一个餐饮试点场景（铁板烧或明档料理）
回复西湖文旅的合作意向，明确移动餐车或固定餐饮的落地方案
推进港大康复合作的阶段性里程碑
9-10月（第二轮融资启动期）：
拓展1-2个新餐饮合作方（王品、开元等），丰富场景组合
启动酒店场景的正式接触（亚朵/华住）
在第二轮融资材料中纳入已有的场景合作成果，增强投资人信心
关键原则：
每个场景先打透一个case，形成可复制的标杆方案，再通过开放平台让行业伙伴去规模化。RoboX的角色是”智能基础设施提供商”，不是餐饮运营商或酒店运营商。
