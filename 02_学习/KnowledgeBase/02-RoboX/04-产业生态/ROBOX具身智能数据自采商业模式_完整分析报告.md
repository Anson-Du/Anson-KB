# 执行摘要

ROBOX作为达摩院前具身智能团队创业项目，核心技术包括TacWM（Tactile World Model，触觉世界模型）、System 2/1/0三层架构、VLA（Vision-Language-Action，视觉-语言-动作模型）成功率90.6%、50万小时第一视角数据。在具身智能赛道中，数据是核心资产，数据采集能力直接决定公司未来估值与商业变现路径。

本报告基于2025-2026年国内已验证的三种代表性数据自采模式——青岛模式（产教融合）、无锡模式（城市级数据基建）、上海模式（三层体系并行），结合ROBOX技术特点，提出"青岛模式启动+无锡机制商业化+ROBOX TacWM差异化"的杭州版本行动策略。

核心结论：
- 硬件三项（FOC驱动器、减速器、Ego采集设备）全部不自研硬件，核心壁垒在模型与数据
- 政府-大学生数据采集模式高度可行，上海/无锡/青岛已跑通先例
- ROBOX的差异化在TacWM"预测性触觉"，与白虎-VTouch/帕西尼的"记录性触觉"形成根本区别
- 三步走：1-2月试点50-100人 → 3-6月扩展500-1000人 → 6-12月产品化输出数据服务
- 终局定位：从"技术公司"到"数据基础设施公司"的估值叙事质变

# 第一章  硬件自研决策分析

ROBOX团队仅4人，没有电机控制、功率电子、精密制造背景。在硬件自研决策上，核心判断标准是：ROBOX的壁垒在模型与数据，不在硬件制造。
## 1.1  FOC驱动器（Field-Oriented Control，磁场定向控制）
结论：不自研。

FOC驱动器是灵巧手最核心的驱动层，但市场已高度成熟：


判断逻辑：
- FOC驱动器的核心壁垒在电流环解耦算法+工艺一致性+功率器件选型，需要10年+积累
- 灵心巧手自研驱动器和减速器花了4年、投入数亿，ROBOX没有这个时间和资源
- 维宏股份的客户网络已覆盖几乎所有头部玩家——标准化模组完全可用
- 推荐合作方：维宏股份（客户验证最强，A股上市有供应链稳定性）或睿研智控（FOC力位混合控制算法与TacWM触觉感知有技术协同）
## 1.2  低反向间隙减速器
结论：不自研。

这是资本密集型精密制造，国产化率已经很高：


关键数据：
- 谐波减速器背隙≤0.5弧分，行星普遍3-5弧分——灵巧手内部100%用微型谐波
- 单台人形机器人用量约26个精密减速器（上肢12-17个谐波+下肢12个行星）
- 全球人形机器人减速器市场：2025年24.7亿→2032年1660亿，CAGR 82.9%
- 灵心巧手创始人周永原话："2019年做第一只灵巧手时尝试在海外采购微型减速器，精度不够、成本太高、无法定制，于是下定决心全栈自研"——只有需要做整只灵巧手时才需要自研减速器，而ROBOX不做灵巧手本体
- 推荐合作方：绿的谐波（量产能力最强，成本最低）或中大力德（谐波+RV双线，性价比）
## 1.3  Ego数据采集设备（Egocentric，第一视角）
结论：硬件不自研，算法自研，联合开发。

这个领域相对年轻（2023-2026），但已出现专业化玩家：


设备成本参考：
- 入门级：GoPro/头戴手机，有效数据率93-95%，成本低
- 高端：六目全景采集设备，单台3000-8000元，有效数据率接近100%
- 数据采集员日薪：兼职150-250元/天，全职月薪5000-7000元

判断逻辑：
- ROBOX已有50万小时数据积累，说明已有采集能力，但设备本身不是壁垒
- 真正的壁垒在数据标注/质控算法和数据格式标准——这恰好是ROBOX的软件优势
- 星忆智能的标注成本缩减99%说明算法价值远大于硬件价值
- 推荐策略：硬件采购简智或星忆标准化采集设备（不自研）；触觉手套与帕西尼合作（PXCap V与TacWM技术天然互补）；算法自研数据标注/质控/标准化算法，输出行业数据格式规范
- ROBOX的终局定位：不是数据采集硬件商，而是数据基础设施/标准制定者

# 第二章  国内代表性数据自采模式

本章详细分析国内已验证的三种代表性数据自采模式——青岛模式、无锡模式、上海模式，每种模式均展开至具体参与主体、运营机制、商业闭环和落地细节。
## 2.1  青岛模式：产教融合人才基地

青岛模式的特点是以职业院校为核心载体，把数据采集嵌入教学过程，成本极低，适合早期启动。
### 2.1.1  核心载体与硬件配置
### 2.1.2  数据采集方式
- 采集方式：主从遥操作（Master-Slave Teleoperation，主从遥操作）——教师操作"主手"（小型控制器），控制"从手"（机械臂）
- 全局相机从不同角度记录手腕转动、指尖力度变化
- 同一动作重复100-200次才能完成一次采集——类比"像教孩子拿筷子，重复100-200次形成肌肉记忆"
- 采集的轨迹数据转化为伺服电机（Servo Motor，伺服电动机）的角度、速度和力度参数
- 数据采集、清洗、标注工作主要由学生完成
- 采集场景：工业制造、医疗、生活、服务
### 2.1.3  企业合作
### 2.1.4  省级背书
- 2026年7月入选山东省（教育厅）首批26家重点建设单位。分类：产教融合训练场
- "院校育人、企业研发、场景实训"一体化平台
- 重点场景：工业智造、智慧康养
- 面向在校师生、企业员工开放：数据采集、算法调试、整机测试
- 面向区域企业开放：产品验证、技术攻关
### 2.1.5  学生收益
- 实操经验：不是实验室"玩"机器人，而是用机器人解决真实问题（维修返修品、开发书签生产线、开发智能采血辅助系统等）
- 学分认证：实训课程纳入专业学分体系
- 实习证明：通过真实项目获得企业认可的实习经历
- 就业竞争力："未毕业、已上岗"，不少学生未出校门已被企业预定
### 2.1.6  关键要点总结
青岛模式验证了"政府-大学生数据采集"设想的可行性——大学生作为采集员、出具实习证明、嵌入教学过程。关键要素：
- 职业院校是最佳合作对象（学生有实践需求，学校有设备采购预算和政策配套）
- 企业售后服务中心落户校内是双赢模式——企业省租金，学校获真实项目
- 省级重点建设名单带来政策背书和资源倾斜
- 年产能1500小时虽然不大，但成本极低（学生"免费"劳动，以学分/实习证明置换）

## 2.3  上海模式：三层体系并行

上海不是单一模式，而是三个层面同时推进，形成了目前国内最完整的具身智能数据生态。
### 2.3.1  第一层：上海市计算机行业协会——"四维联动"商业模式
时间：2026年7月11日召开研讨会，正在长三角推广
核心架构："政府 + 独角兽 + 学校 + 场景"四维联动
运作机制：
- 国资平台作为采购主体，持有采集设备资产（解决设备成本问题）
- 第三方受托进行数据采集与训练（执行层）
- 协会及合作伙伴承接数据运营（中间层）
- 独角兽企业提供品牌背书和技术标准（需求方）
商业闭环（参考浙江德清基地已验证模式）：
数据采集 → 数据确权 → 与场景方（养老院、急救中心等）按比例分成 → 将数据出售给机器人公司
"AI微专业"进校园——关键创新：
- 课程由人工智能研究院与协会共同开发，涵盖数据标注、智能体开发
- 上海交通大学已开设并授予学分
- 协会提供"课程 + 设备 + 申报材料"完整解决方案
- OPC（Open Platform for Computing，开放计算服务平台）服务平台实现"一次开发、多地复用"
- 学校可利用产教融合专项资金采购设备与课程服务
### 2.3.2  已跑通标杆：浙江德清基地
这是协会在研讨会上明确引用的"成功模式"，也是目前国内跑通数据采集→确权→分成→交易闭环最成熟的案例。

德清模式的数据交易机制：
- 无问智科自建训练场，自采数据 + 仿真合成数据
- 数据产品直接出售给机器人公司（星动纪元、字节跳动等），按小时计费
- 2026年市场价参照：真机数据500-1000元/小时，无本体数据300-400元/小时
- 同一数据可复售给多个客户（优质场景复售率超10倍），边际成本近零
- 这就是"一次采集，多次变现"的核心商业逻辑

# 第六章  总结与建议
## 6.1  核心判断
1. 硬件自研：三项全部不自研硬件
ROBOX的核心壁垒在模型与数据，不在硬件制造。FOC驱动器市场已被MPS/维宏/睿研智控等占领，减速器市场已被绿的谐波/中大力德等占领——这些都是10年+积累的精密制造领域，4人团队没有任何理由从头自研。Ego采集设备已有简智/星忆/帕西尼等专业玩家，采购标准设备即可。真正应该自研的是数据标注/质控算法和数据格式标准。

2. 政府-大学生数据采集：高度可行
这不是空想——上海/无锡/青岛已经跑通了"政府搭台+企业出标准+大学生采集+数据确权"的模式。Anson的独特优势是南湖未来科学园200+企业网络和余杭区政府关系，这让你比任何人都更有条件落地。

3. ROBOX差异化：TacWM预测性触觉
无锡-帕西尼的5.0范式和白虎-VTouch都在做触觉数据，但它们的触觉传感器是视触觉（VBTS）路线——记录触觉图像。ROBOX的TacWM是"触觉世界模型"——预测性触觉，不只是记录触觉反馈。这是ROBOX数据产品与它们根本不同的地方，需要在数据格式和标注体系中体现出来。
