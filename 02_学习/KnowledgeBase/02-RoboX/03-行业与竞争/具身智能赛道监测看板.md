# 具身智能赛道监测看板
整理日期：2026年8月8日 | 覆盖5个细分赛道、30家公司 | 供内部参考

# 看板说明
本看板覆盖具身智能领域5个细分赛道共30家头部公司，重点关注灵巧操作研发进展、场景拓展、关键客户突破、商业模式及相互合作信息。数据来源为公开信息整理，部分数据可能存在滞后，建议每季度更新一次。

# 赛道一：触觉感知与模型（5家）
赛道特征：两条技术路线分化——伪标签路线（从视频推断触觉）vs 物理传感器路线（真实触觉信号）。核心竞争维度是数据规模和触觉融入预训练模型的进度。

关键洞察：
- 1. 智在无界是ROBOX在触觉维度最直接的竞争对手——50万小时数据量领先ROBOX 62.5倍，且已将触觉融入预训练模型。
- 2. 帕西尼感知的传感器全球市占率80%，已从硬件公司升级为"传感器→数据→模型"全栈平台，估值超100亿。
- 3. 帕西尼触觉传感器从10万/片降至199元/片，价格螺旋建立了不可逾越的成本护城河。
- 4. 伪标签路线(智在无界) vs 物理传感器路线(帕西尼/ROBOX)是赛道核心分歧——前者规模化快但牺牲真实性。

# 赛道二：灵巧手/末端执行器（5家）
赛道特征：2025年出货超2万台，2026年预计7万台。行业从"参数竞赛"转向"量产稳定性+真实场景价值"。灵心巧手估值已达200亿+，临界点成立5个月即成独角兽。

关键洞察：
- 1. 灵心巧手是赛道绝对龙头——全球高DOF灵巧手市占80%+，估值200亿+，目标424亿(60亿美元)，计划2027港股IPO。
- 2. 因时机器人是量产先驱——2025年全球唯一万级出货(1万台+)，客户覆盖所有头部本体厂商，累计融资6亿。
- 3. 临界点(智元拆分)创最快独角兽纪录——成立5个月估值破10亿美元，LG首款人形机器人搭载其灵巧手。
- 4. 帕西尼从传感器切入灵巧手——1140个触觉传感单元+ITPU芯片，"传感器→灵巧手→数据→模型"全栈最完整。
- 5. ROBOX与因诺特的co-design合作需重新评估——因诺特未在头部5家中出现，行业格局已向灵心巧手/因时/帕西尼集中。

# 赛道三：整机本体/人形机器人（10家）
赛道特征：2026上半年国内具身智能融资935亿元，22家估值超百亿。整机公司从"demo驱动"转向"量产+场景"驱动。关键分化：全身人形 vs 双臂桌面；ToB商业服务 vs ToC家庭。

关键洞察：
- 1. 整机赛道估值分化极大——Figure AI 390亿美元 vs 蚂蚁灵波80亿人民币，差距超35倍。
- 2. 智元机器人估值1400亿为国内最高，已拆分灵巧手业务(临界点)独立融资，构建"本体+灵巧手+数据"生态。
- 3. 宇树科技是唯一已盈利的整机公司——电商直销模式+四足机器人积累，2026春晚亮相后品牌效应显著。
- 4. 多数整机公司的灵巧手操作能力仍然薄弱——宇树假手仅3DOF/手，银河通用用夹爪非灵巧手。真正的灵巧操作仍需ROBOX级别的System 2/1/0支撑。
- 5. Figure AI是ROBOX在全球范围的终极对标——自研灵巧手+VLA模型+OpenAI合作+BWM/亚马逊客户，但尚未进入中国。

# 赛道四：数据采集与服务（5家）
赛道特征：定价200-500元/小时，优质数据复售超10倍。行业从"采集"升级为"数据基座+仿真+评测"全链路。光轮智能估值150亿为赛道独角兽，无问智科日产千小时。

关键洞察：
- 1. 光轮智能是全球具身数据领域首个独角兽(150亿)——人类视频数据交付量全球第一，国际主要具身团队80%+仿真资产来自光轮。
- 2. 穹彻智能是ROBOX在大脑模型赛道的直接竞争者——120B参数具身大脑(全球最大)，"力位混合"路线与ROBOX"手眼脑协同"有理念重叠。
- 3. 无问智科德清基地"日产千小时"已验证——三层训练体系(室内3000㎡+室外505亩+全域937㎢)，ROBOX数据采集模式可直接参照。
- 4. 弈人科技是唯一已盈利的数据公司——千万车辆众包感知网络成本极低，百亿级时空数据可跨售，30人团队人均效率极高。
- 5. 帕西尼的5座数据工厂模式——"硬件造数据→数据哺模型→模型优硬件"闭环，是ROBOX数据飞轮的竞品参照。

# 赛道五：具身大脑/VLA模型（5家）
赛道特征：VLA (Vision-Language-Action) 模型是具身智能的核心。关键分化：System 2/1/0分层 vs 端到端单模型；AR架构 vs diffusion架构；纯模型公司 vs 模型+本体公司。

关键洞察：
- 1. 穹彻智能是ROBOX在大脑模型赛道的最直接竞争者——120B参数(全球最大)、40亿估值、"力位混合"理念与ROBOX"手眼脑协同"有重叠。
- 2. 智在无界虽是触觉赛道，但其Being-H0.8本质上是一个"含触觉的具身大脑模型"——与ROBOX System 2定位重叠。
- 3. 自变量15亿美元估值但Fanny评价"demo不如ROBOX"——说明ROBOX的demo质量在赛道中处于领先水平。
- 4. 元力无限150亿估值但被明修评价"像一条灵活的狗"、被沈千旸评价"灵活但无使命"——高估值≠技术领先。
- 5. ROBOX的差异化在于System 2/1/0三层架构——其他玩家要么做单层(穹彻只做大脑层)、要么做端到端(智在无界)，ROBOX是唯一做分层+latent space通信的。

# 跨赛道合作图谱
以下梳理各赛道玩家之间的已知合作关系，帮助识别行业生态结构和ROBOX的潜在合作/竞争边界。

# ROBOX定位与监测优先级

ROBOX监测策略总结：
- 1. P0级别两家直接竞争者(智在无界、穹彻智能)需月度跟踪——它们在数据量和模型迭代上领先ROBOX，是ROBOX"追时间"的直接对象。
- 2. 帕西尼感知是"亦敌亦友"——传感器全球垄断但与ROBOX无直接竞争，是触觉手套和数据采集的潜在合作伙伴。
- 3. 灵巧手赛道(灵心巧手/因时/临界点)对ROBOX是"下游"而非竞争——它们是ROBOX System 1/0端侧模型的潜在部署载体。
- 4. 整机赛道(智元/宇树/Figure)对ROBOX是"客户"而非竞争——它们需要ROBOX的大脑来驱动灵巧手操作。
- 5. 数据服务赛道(光轮/无问/弈人)对ROBOX是"参照"而非竞争——ROBOX自建数据飞轮，但可参照其商业模式和定价。
