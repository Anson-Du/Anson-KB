# 触觉模型赛道玩家与技术路线分析
整理日期：2026年8月8日 | 供内部参考

# 一、赛道概述
触觉感知是具身智能中"手眼脑协同"的关键一环。当前赛道呈现两条技术路线分化：一条是以智在无界为代表的"从视频中推断触觉信息"的伪标签路线，绕过物理传感器瓶颈；另一条是以帕西尼感知为代表的"物理触觉传感器+真实触觉数据"路线，数据质量高但规模化成本高。ROBOX的TacWM (Tactile World Model，触觉世界模型)采用后者路线，但通过"手机APP→仿真→真机→触觉手套"四步管线实现规模化，介于两者之间。
# 二、头部玩家详细分析
## 2.1 智在无界 (BeingBeyond)
核心标签：全球首个隐式触觉世界动作模型 | 50万小时Ego数据全球第一

核心技术——TactoHand密集触觉伪标签系统：
从普通第一人称视频中推断人手与物体的接触点概率和接近度，不需要物理触觉传感器即可获得"近似触觉"信息。这一技术绕过了"触觉数据太少"的瓶颈——将视觉数据转化为触觉信号的近似表示，实现规模化。
对ROBOX的竞争含义：
智在无界已经做到了明修所说"未来才有机会做"的事——将触觉融入预训练模型。其TactoHand伪标签技术绕过了ROBOX当前面临的数据瓶颈。但两者的定位有本质差异：智在无界是纯模型公司，ROBOX是System 2/1/0三层架构+Action VAE全栈。

# 五、关键竞争洞察
1. 伪标签 vs 物理传感器——两条路线的本质差异
智在无界的TactoHand伪标签技术从普通视频中推断接触信息，不需要物理传感器，实现了规模化但牺牲了触觉信号的真实性。帕西尼和ROBOX采用物理传感器路线，数据质量高但规模化受限于传感器部署成本。明修说"我缺的数据"——正是指物理触觉数据的规模不足。
2. 智在无界的先发优势已构成直接竞争压力
Being-H0.8已将触觉融入预训练模型，数据量50万小时远超ROBOX的8,000小时。明修在0807版中将数据目标大幅上调（10万→200万→1000万），直接动因之一就是追赶智在无界。但明修的逻辑是"数据不够所以先做规模化"，而非"不做触觉模型"——方向一致，时序策略不同。
3. 帕西尼感知的"传感器垄断+数据工厂"模式最具商业壁垒
全球80%人形机器人采用帕西尼传感器，传感器从10万/片降至199元/片的价格螺旋建立了不可逾越的成本护城河。5座数据工厂年产百亿条数据，形成"硬件造数据→数据哺模型→模型优硬件"闭环。ROBOX不自研传感器（采用数觉），与帕西尼在触觉数据层面存在潜在合作而非竞争关系。
4. ROBOX的差异化在于"统一大脑"而非"单独触觉模型"
其他玩家要么做独立触觉模型（智在无界），要么做传感器+模型全栈（帕西尼/无界智航）。ROBOX的独特之处在于System 2/1/0统一架构——视觉、触觉、动作都在同一个latent space中通信。单独做触觉模型不符合ROBOX"统一大脑"的架构理念。
5. 数据规模是当前最紧迫的竞争维度
智在无界50万小时 vs ROBOX 8,000小时——差距62.5倍。即使按明修0807版调整到10万小时（一期目标），仍落后5倍。明修将数据目标上调至200万（三期）和1000万（四期），正是在回应这一竞争压力。ROBOX的数据飞轮（部署→采集→训练→部署）需要尽快启动才能缩小差距。

# 六、建议
1. 对外沟通策略
不应贬低智在无界的技术路线。建议话术："我们在数据规模上正在快速追赶，同时System 2/1/0三层架构和真实触觉数据管线是长期壁垒。"帕西尼是潜在合作伙伴而非竞争对手——可探讨采购帕西尼触觉手套用于数据采集。
2. 内部时间线确认
建议在合适时机直接问明修："智在无界的Being-H0.8已经把触觉融入预训练了，我们的时间线是什么？"明修0807版数据目标大幅上调（10万→200万→1000万）是在回应竞争压力，需确认配套算力和人员是否匹配。
3. 数据飞轮加速
ROBOX的数据飞轮（部署→采集→训练→部署）需要尽快启动。当前8,000小时的数据量在赛道中处于明显劣势。建议优先启动政府-大学生数据采集模式（青岛模式），利用低成本社会化采集快速积累Ego数据。
4. 差异化叙事强化
对外强调ROBOX的三个独有壁垒：(1) System 2的122B千亿参数大脑——其他触觉玩家均无此层级；(2) Action VAE连续动作生成——解决chunk-to-chunk抖动；(3) 多机器人co-training——Unified Action Space跨本体适配。这三个壁垒是智在无界和帕西尼都不具备的。
