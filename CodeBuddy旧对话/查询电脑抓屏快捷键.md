## 🤖 助手

Windows 系统自带的截屏快捷键主要有以下几个：

| 快捷键 | 功能 |
|--------|------|
| **PrtScn**（Print Screen） | 截取整个屏幕，复制到剪贴板 |
| **Win + PrtScn** | 截取整个屏幕，自动保存为图片文件（默认存到 `图片/屏幕截图` 文件夹） |
| **Alt + PrtScn** | 截取当前活动窗口，复制到剪贴板 |
| **Win + Shift + S** | 唤出自带截图工具（可选矩形、任意形状、窗口、全屏），截取后复制到剪贴板 |
| **Win + W** | 唤出"屏幕草图"（部分 Windows 版本可用） |

其中最常用的是 **Win + Shift + S**，可以自由选择截图区域，截完直接粘贴到聊天框或文档里即可。

> 另外如果你装了微信/QQ，它们也有自己的截图快捷键：微信是 **Alt + A**，QQ 是 **Ctrl + Alt + A**。

核心就两个模式，搞懂这两个就够了：

| | Chat 模式 💬 | Craft 模式 🔨 |
|---|---|---|
| 干什么 | 问问题、看代码、要建议 | 直接帮你写代码、改文件 |
| 改你文件吗 | **不改**，结果给你看 | **直接改**，但有 Checkpoint 可回滚 |
| 什么时候用 | 不确定方案时先问 | 方案确定了让它干 |

**上手 4 步走：**

1. 打开 CodeBuddy IDE → 新建文件夹或打开已有项目
2. 按 `Ctrl+Shift+V` 打开左侧对话面板，切到 **Craft** 模式
3. 直接用中文描述需求，比如「帮我做一个产品展示网页，三列卡片布局，蓝白配色」
4. AI 自动创建文件、生成代码，不满意继续对话修改，误操作了点 Checkpoint 回滚

**几个关键操作：**
- 右键文件 → **Add File to CodeBuddy**：把文件丢给 AI 当上下文
- `Ctrl+V` 粘贴截图：让 AI 看着设计稿写代码
- `Tab`：接受 AI 的代码补全建议
- 输入 `/explain`：解释选中代码；`/fix`：修复问题；`/tests`：生成测试

## 🤖 助手

Windows 找隐藏文件夹很简单，两种方式：

---

**方法一：文件资源管理器设置（最常用）**

1. 打开任意文件夹（或按 `Win + E` 打开资源管理器）
2. 点击顶部菜单栏的 **「查看」** 选项卡
3. 勾选 **「隐藏的项目」**（Windows 11 是：查看 → 显示 → 隐藏的项目）

隐藏的文件夹就会以半透明图标显示出来。

---

**方法二：文件夹选项（更彻底，连系统文件也能看到）**

1. 打开资源管理器，点击 **「查看」** → **「选项」**（右上角，也叫「更改文件夹和搜索选项」）
2. 切到 **「查看」** 标签页
3. 找到并选择：
   - ✅ **显示隐藏的文件、文件夹和驱动器**
   - 如果连系统保护文件也想看，取消勾选 ❌ **隐藏受保护的操作系统文件**
4. 点 **「确定」**

---

**方法三：直接在地址栏输入路径**

如果你记得文件夹路径，直接在资源管理器地址栏输入完整路径回车即可，不管藏没藏都能进。比如：

```
D:\MyFolder
```

---

**补充：如果你是自己用命令隐藏的**

在终端里用 `attrib` 命令可以查看和取消隐藏属性：

```bash
# 查看某目录下所有文件属性（包括隐藏的）
attrib "D:\你的路径\*"

# 取消隐藏属性
attrib -h "D:\你的路径\文件夹名"
```

## 方式一：同账号登录自动同步（最简单）

适用于 **CodeBuddy IDE / 桌面客户端 + 移动端 App**

1. 电脑端：安装 CodeBuddy 桌面版或 IDE 插件，用**微信扫码**登录
2. 手机端：下载 CodeBuddy App（iOS 在 App Store 搜「CodeBuddy」，Android 从官网 `codebuddy.ai/download/android` 下载 APK）

## 方式二：Remote Control 远程控制（CLI 用户）

适用于 **CodeBuddy Code (CLI 命令行工具)**

```
/gateway
```

- 一个 **二维码**（终端中显示）
- 一个 Web UI 链接（带认证 token）
- 一个局域网地址

**连接方式（任选其一）：**

| 方式 | 操作 |
|------|------|
| 扫码连接 | 手机扫描终端里的二维码，直接打开 Web UI |

| 局域网 | 同一 WiFi 下访问 `http://你的电脑IP:8321` |

**两种网络模式：**
- **Tunnel 模式**（默认）：通过 Cloudflare 隧道分配临时公网域名，手机用 4G/5G 也能连
- **局域网模式**：仅同一 WiFi 内可访问，速度更快

> 关键：所有代码执行都在你的电脑本机跑，手机只是一个远程窗口。

**相关命令：**

| 命令 | 功能 |
|------|------|
| `/gateway` | 启动远程控制 |
| `/gateway status` | 查看状态 |
| `/gateway stop` | 停止 |
| `/gateway token` | 重新生成认证 token |
