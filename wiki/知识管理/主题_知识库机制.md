# 主题_知识库机制（本机制自述页）

> 机制文档在 schema/｜首期编译 2026-09-25

## 概述

本知识库（`~/Documents/Anson`）采用 Yiki 分享的「采集 → 原料 → 编译 → 知识 → 查询 → 策展」机制：原始材料只进不改，AI 按明文规则定期提炼成结构化知识页，人每周约 10 分钟策展。

## 关键信息

- **四层架构**：原料层（00–08 目录 + codebuddy-memory + CodeBuddy旧对话，只读）→ 规则层（schema/ 白盒）→ 编译层（wiki/，仅管线生成）→ 工具层（scripts/）
- **页面四类型**：`主题_`/`实体_`/`概念_`/`来源_`，统一模板（概述→关键信息→时间线→来源→关联）
- **AI 五红线**：不改原料、不覆盖人工 wiki 编辑、不删旧结论、不编造来源、不写未确认内容
- **查询优先级**：wiki → 原料层 → 网络（已写入 AI 用户级长期记忆，新会话自动生效）
- **调度**：launchd 每日 10:00 同步（记忆镜像 + git 提交）；每周日自动编译（CodeBuddy 自动化）；触发词随时手动
- **版本管理**：本地 Git + GitHub 私有远端（音频/工作区/超大文件不入库，见 .gitignore）
