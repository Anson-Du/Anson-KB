# 主题_云康实验室自动化合作

> 编译自：01_工作/RoboX/06_应用场景&生态/医学检测：云康（Pasontech）｜首期编译 2026-09-25

## 概述

RoboX 与云康集团（ICL，Independent Clinical Laboratory，独立医学实验室）的具身智能 + 生命科学实验室自动化战略合作，已签 MOU 草案。核心是分阶段落地路径与 IP 隔离原则，试点场景聚焦高频高价值且不直接接触患者身体的环节。

## 关键信息

- **分阶段路径**：P1 Demo 实验室（杭州，ROBOX 管理，云康设备租借）→ P2 联合实验室（杭州 + 广州）
- **试点场景（候选）**：分液/移液、细胞培养 72 小时"三次转换"、病理组织切片捞片
- **场景原则**：高频高价值 + 不接触患者身体；明修判断"康复≠养老、康复医院≠医院康复科"，需在 MOU 中区分
- **IP 隔离**：背景 IP 各自归属，合作产出另行约定
- **对接人**：云康集团庄磊（08-16 场景合作探讨）
